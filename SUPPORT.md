# Support

## Questions and usage help

Search the [documentation](docs/) and existing [GitHub issues](https://github.com/DEVN0W/DevNow-Agent/issues) first. If the answer is not available, open a GitHub issue with your operating system, DevoNow revision, model provider, relevant configuration with secrets removed, and steps to reproduce the problem.

## Bug reports and feature requests

Use the repository's issue templates for reproducible bugs and focused feature proposals. Community support is provided on a best-effort basis; response times are not guaranteed.

## Private AI deployments

Organizations interested in the licensed private Ollama deployment can [contact the DevoNow team](https://github.com/DEVN0W/DevNow-Agent/issues/new). Do not include credentials, proprietary code, or sensitive infrastructure details in a public issue.
